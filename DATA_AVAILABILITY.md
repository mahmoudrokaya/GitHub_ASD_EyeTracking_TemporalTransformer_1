# Data Availability

This repository primarily provides source code, experiment definitions, metadata permitted for release, and reproducibility materials. Raw eye-tracking data and third-party datasets may be omitted because redistribution can be governed by provider terms, ethics approval, consent conditions, privacy requirements, or file-size constraints.

Before publication, add the verified dataset title, provider, official URL or DOI, license, access restrictions, version/download date, and experiment mapping for every dataset used.
